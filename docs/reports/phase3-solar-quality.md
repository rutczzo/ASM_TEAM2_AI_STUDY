# Solar 기반 추천 품질 고도화 보고

## 목표

기존 LangGraph 배선과 규칙 기반 전략을 유지하면서, 규칙만으로 놓치기 쉬운 사용자 의도를
Solar가 보강하도록 개선했습니다. Solar 호출 실패 시 기존 규칙 결과로 폴백하므로 로컬 데모
경로도 유지됩니다.

## 변경 사항

| 영역 | 현재 동작 |
|---|---|
| 확인 답변 판정 | 추가 답변을 무조건 승인하지 않고 Solar로 충분성을 재판정합니다. |
| 질문 종료 조건 | 확인 질문은 한 번에 하나씩, 최대 2회까지만 수행하고 이후 누적 입력으로 진행합니다. |
| 약점 분석 | 규칙 기반 `GapContext`를 먼저 만들고 Solar가 누락·오판과 검색 힌트를 보정합니다. |
| 구체 요구 보존 | 로그 관측성처럼 사용자가 명시한 세부 요구를 일반 카테고리로만 축약하지 않습니다. |
| 후보 평가 | 기존 적합도 65%와 Solar 의도 일치도 35%를 혼합해 검색된 후보만 재순위화합니다. |
| 멘토 데이터 | 기술 중심 10명에서 게임, 창업, 성장, 브랜딩, ML, 데이터, 모바일, SRE, IoT를 포함한 20명으로 확장했습니다. |

## 안전장치

- Solar 응답은 Pydantic 스키마로 검증합니다.
- 약점 카테고리는 기존 허용 분류 체계 안에서만 사용합니다.
- 후보 재순위화는 검색된 모든 후보 ID가 정확히 반환될 때만 적용합니다.
- 후보 누락, 중복, 잘못된 ID, API 오류가 있으면 기존 규칙 결과와 순위를 유지합니다.
- 테스트에서는 `SOLAR_ANALYSIS_ENABLED=false`로 외부 API 호출과 비용 발생을 막습니다.

## 설정

```env
UPSTAGE_API_KEY=
SOLAR_ANALYSIS_ENABLED=true
SOLAR_MODEL=solar-pro3
SOLAR_BASE_URL=https://api.upstage.ai/v1
SOLAR_TIMEOUT=20
```

키가 없거나 `SOLAR_ANALYSIS_ENABLED=false`이면 규칙 기반 분석과 BM25 검색만으로 동작합니다.

## 점수 해석

멘토 카드의 적합도는 절대 능력 점수가 아닙니다. 현재 사용자 요청과 검색 후보 안에서의
상대적 적합도를 나타냅니다. Solar는 구체 사용자 의도를 반영해 순위를 보정하므로 입력에 따라
점수 분포가 크게 달라질 수 있습니다.

## 검증

- 모호한 입력이 확인 질문을 무한 반복하지 않고 최대 2회 후 진행하는지 검증
- RPG 입력에서 게임 개발·기획 멘토가 검색되는지 검증
- 관측성·장애 대응 요구에서 SRE 후보가 범용 인프라 후보보다 우선될 수 있는지 검증
- Solar 실패 및 잘못된 응답에서 기존 규칙 결과가 보존되는지 검증
- 현재 전체 테스트: **109개 통과**
